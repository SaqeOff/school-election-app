# 🇰🇿 Школьные Выборы Парламента | Мектеп Парламенті Сайлауы

Современная система онлайн-голосования для выборов Президента Школьного Парламента в Казахстане с защитой от накрутки, верификацией по базе учеников (ФИО + ИИН) и результатами в реальном времени.

## 🚀 Особенности

- 🔒 **Защита от накрутки**: Однократная верификация по базе учеников. Повторный голос с одного ИИН невозможен.
- 🗳️ **Кабина голосования**: Карточки кандидатов, программы, предвыборные тезисы и модальное подтверждение.
- 📊 **Live-Результаты**: Автоматический пересчёт голосов, процентовка, статистика явки и корона лидеру гонки.
- 🔑 **Панель Избирательной Комиссии**: Мониторинг проголосовавших, экспорт протокола в CSV, сброс/перезапуск выборов (пароль: `admin123`).
- 🌐 **Двуязычность**: Поддержка казахского (Қазақша) и русского языков.
- ⚡ **Zero-dependency**: Работает быстро и без сложных бэкендов — развертывается за 1 клик на Vercel/GitHub Pages/Netlify.

## 📁 Структура проекта

```
├── assets/             # Фотографии кандидатов и графические ресурсы
├── index.html          # Главная страница приложения
├── style.css           # Современные адаптивные стили (Kazakh Sky Blue + Gold)
├── app.js              # Логика верификации, подсчета и админки

```

## 🛠️ Локальный запуск

Откройте `index.html` в любом браузере или запустите локальный сервер:
```bash
python -m http.server 8080
```
И перейдите на `http://localhost:8080`.

## 🌐 Развертывание на Vercel

1. Загрузите репозиторий на свой GitHub.
2. Перейдите на [vercel.com](https://vercel.com) и войдите через GitHub.
3. Нажмите **"Add New..."** -> **"Project"**.
4. Выберите репозиторий и нажмите **"Deploy"** (настройки сборки менять не нужно).
5. Сайт готов и доступен по бесплатной публичной ссылке!
